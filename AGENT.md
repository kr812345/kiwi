# Agent Instructions

These instructions must be strictly followed when developing or contributing to the **Kiwi** repository:

1. **Human-Readable Code**:
   - Write clean, intuitive, and easy-to-understand code for human developers.
   - Use meaningful names, clear structure, and sensible abstractions.

2. **Efficient & Precise Implementation**:
   - Write lean, efficient code with zero unnecessary fluff or bloat.
   - Implement strictly what is asked and required—no speculative features or unneeded complexity.

3. **Developer Documentation Maintenance**:
   - Maintain [DEV_NOTES.md](file:///root/kiwi/DEV_NOTES.md).
   - On every new feature implemented or engineering decision made that is worth knowing to future developers, append/update short, easy-to-understand bullet points.
